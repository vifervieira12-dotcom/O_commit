# 🌐 Vortex Tech — Front-End

Esta pasta contém toda a interface visual e interativa da loja **Vortex Tech**.

## 📁 Arquivos desta pasta:
- `index.html`: Página principal (Apresentação, Destaques, Formulário de Contato/Pedido e Chatbot Flutuante).
- `loja.html`: Página do catálogo completo da loja, com filtros por categoria, busca por texto e ordenação por preço.
- `style.css`: Estilização visual completa (design moderno, responsivo para celular e computador, tema escuro tech).
- `script.js`: Código JavaScript da página principal (envio do formulário para o backend e funcionamento do chatbot).
- `loja.js`: Código JavaScript da loja (carrega produtos do banco via API e aplica os filtros na tela).
- `img/`: Fotos dos produtos (smartphones, fones, smartwatches, carregadores).
- `logo-vortex.png` e `hero-bg.jpg`: Logotipo e imagem de destaque do cabeçalho.

## 🚀 Como testar visualmente:
Você pode abrir o `index.html` ou `loja.html` diretamente em qualquer navegador (dando duplo clique).  
*Nota: Para que o chatbot com IA, a busca no banco de dados e o formulário funcionem, é necessário que o servidor em `back-end` ou em `site-completo` esteja ligado.*
